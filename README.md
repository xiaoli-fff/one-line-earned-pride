One line of quiet, earned pride: on his last night, a lighthouse keeper polishes the lamp, watches its beam sweep the black water, and nods at the dark as if it nodded back.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
